# Zoho CRM fields used by the Client Portal

> Generated by `python -m app.cli field-docs` from `app/zoho/field_catalog.py`. Do not edit by hand.
> The same list, with a live found/missing check against your org, is in the admin console under **Zoho setup**.

API names below are the defaults. If your org already uses different names, keep your fields and set the matching
`CRM_*` variable in `.env` (see `app/config.py`).

## Checklist: what to create in Zoho

1. **Custom module `Properties`** with the fields marked *Create* below.
2. **Deals: `Property`** (Property, Lookup (Properties)).
3. **Leads: `Portal_Match_Criteria`** (Portal Match Criteria, Multi-line).
4. **Leads: `Referred_By`** (Referred By, Lookup (Contacts)).
5. **Leads: `Inquiry_Type`** (Inquiry Type, Picklist (Buying a home, Land or a lot, Selling a property, Renting, Investment property)).
6. **Leads: Lead Source picklist values `Portal Sign-up` and `Client Referral`**.
7. **Properties: Status picklist value `Available`** for listings clients may see.

Everything else is a standard Zoho field. In total: 40 fields across 6 modules, 17 to create.

## Contacts (`Contacts`): Standard module

The client. One client login is linked to one Contact, and only once they have an active deal.

| Field label | API name | Type | Required | Create? | Used for |
|---|---|---|---|---|---|
| First Name | `First_Name` | Single line | Optional | Standard | Greeting on the dashboard |
| Last Name | `Last_Name` | Single line | Yes | Standard | Client name |
| Email | `Email` | Email | Yes | Standard | Matches the portal login to this Contact |
| Phone | `Phone` | Phone | Optional | Standard | Shown on the client profile |
| Mobile | `Mobile` | Phone | Optional | Standard | Used when Phone is empty |
| Contact Owner | `Owner` | User lookup | Yes | Standard | The client's agent (name, email, phone in the portal) |

## Notes (`Notes`): Standard module

Client messages are saved as Notes titled "[Client Portal] …". Agents reply with a Note titled "[Portal Reply] …". No new fields needed.

## Tasks (`Tasks`): Standard module

Each client message creates a high-priority Task for the agent. No new fields needed.

## OAuth scopes

`ZohoCRM.modules.ALL, ZohoCRM.coql.READ, ZohoCRM.settings.fields.READ, ZohoCRM.users.READ`

For least privilege, narrow `modules.ALL` to: read on Contacts, Deals and Properties; create and update on Leads; create on Notes and Tasks.
